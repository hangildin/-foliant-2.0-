# Foliant 2.0

Демонстрационный прототип новой цифровой упаковки казанского издательства «Фолиант».

## Задача

Не просто показать, что «Фолиант» умеет печатать, а быстро довести клиента до одного из трёх действий:

1. создать книгу под ключ;
2. рассчитать печать готового проекта;
3. получить коммерческое предложение для закупки/тендера.

## Логика прототипа

Структура собрана на основе российских референсов книжного и полиграфического рынка: продуктовая сегментация, кейсы, полный цикл, конкретный CTA и короткий бриф вместо перегруженного калькулятора.

## Что уже есть

- адаптивная главная страница;
- два основных клиентских сценария;
- блок проектов/кейсов;
- понятный процесс работы;
- позиционирование издательства;
- интерактивный бриф, который собирает заявку без backend;
- ссылки на VK и Telegram «Фолианта».

## Что заменить после получения материалов издательства

- прототипные обложки на реальные фотографии книг;
- демонстрационные кейсы на реальные проекты;
- подтверждённые цифры и факты;
- форму-бриф подключить к Telegram/CRM;
- добавить контакты и реквизиты;
- при необходимости сделать отдельные SEO-страницы под ключевые продукты.

## Файлы

- `index.html` — структура страницы;
- `styles.css` — визуальная система и адаптив;
- `script.js` — анимации, модальное окно и бриф.

Прототип специально сделан без тяжёлого фреймворка: его можно бесплатно опубликовать через GitHub Pages или Netlify и показывать с телефона как обычный сайт.
